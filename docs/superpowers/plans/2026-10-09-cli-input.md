# CLI input and option parsing

## Goal

Port the option and one-shot prompt semantics into a reusable Go package, keeping process startup and presentation in the later command entry point.

## Tasks

- [x] Test print/JSON, selection flags, leading preset, resume modes, conflicts, positional rules, and action flags.
- [x] Parse interspersed options, short clusters, unique GNU long-option prefixes, and `--` termination.
- [x] Port prompt argument joining, piped input, final newline trimming, empty prompt, and promptless resume behavior.
- [x] Run full test, race, build, and vet checks.

## Progress

`internal/cli` provides a pure parser and prompt reader. Help/version are represented as actions so the root command can render and exit without coupling argument interpretation to process I/O.

Verification passed: `go test -race -count=1 ./...`, `go test -count=1 ./...`, `go build ./...`, and `go vet ./...`.
